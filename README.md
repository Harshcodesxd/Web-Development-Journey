## 🏃 How to Run the Code Locally

### 1. Web Projects (HTML / CSS / Tailwind / DOM)
* Open the directory in **VS Code**.
* Use the **Live Server** extension (Right-click on `index.html` ➔ *Open with Live Server*), or double-click any `.html` file to preview it in your browser.

### 2. JavaScript Practice Files
Ensure [Node.js](https://nodejs.org/) is installed on your system. Run any file using:
```bash
node "JavaScript/Lecture 47 - Async Await, Promise Methods, Error handling/index.js"
```
