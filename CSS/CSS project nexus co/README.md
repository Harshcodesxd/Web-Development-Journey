# 🧢 NexusCo

A streetwear storefront concept and my first project using **HTML and CSS**. I built it to practice creating a multi-page website and styling a consistent brand experience.

## 👀 Preview

The homepage introduces NexusCo, a streetwear brand concept featuring weekly product drops and featured items.

## ✨ Features

- 🏠 Homepage with a promotional hero section
- 👕 Product listings and product detail page
- 🔥 Featured drops and bestseller sections
- 📖 Brand story and product highlights
- 📬 Contact page
- 🛒 Shopping cart and social media links

## 🛠️ Built With

- HTML
- CSS

## 🚀 Getting Started

No installation is needed.

1. Clone or download this repository.
2. Open `index.html` in your browser.

## 📄 Pages

- `index.html` — Homepage
- `products.html` — Product listings
- `product details.html` — Product details
- `contact.html` — Contact page

## 💡 About This Project

This was my first HTML and CSS project. It helped me learn how to structure web pages, style layouts, and bring a storefront concept to life.
