Positions in CSS

1. Static (by default), content ka normal flow | Static is the default position of an element. It does not accept properties like top, left, right, or bottom.

2. Relative - Relative positioning places an element relative to its normal position. You can move it using top, left, right, or bottom.

3. Absolute - Absolute positioning removes the element from the document flow and places it relative to the nearest ancestor with a positioning context (relative, absolute, or fixed).

4. Fixed - Fixed positioning removes the element from the flow and positions it relative to the viewport. It remains in place even when the page scrolls./h3>

5. Sticky - Sticky positioning switches between relative and fixed based on the scroll position.
